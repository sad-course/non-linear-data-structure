### Executando o algoritmo de busca A* e Guloso

```bash
python -m venv venv
```

```bash
source venv/bin/activate
```

```bash
pip install pygame
```

```bash
python main.py
```

### Comandos

Tecla S -> para definir o bloco de Início (Amarelo)

Teclas E -> para definir o bloco de Chegada (Vermelho)

Tecla W -> para definir o(s) bloco(s) de parede (Preto)

Tecla C -> para limpar o grid

Tecla Espaço -> para executar o algoritmo

Tecla Tab -> alternar entre guloso e A*

**Para inserir os blocos, clique com o botão esquerdo do mouse.**

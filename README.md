### Non Linear Data Structure (NLDS)

Different from linear data structure, it consists in a structure that holds data not 
following a sequential organization.
Linear Data Structure are useful for trivial situations especially for random access and not to good 
for insertions and delete that in worst case could cost O(n) time complexity.

NLDS are a different approach to lead with complexities algorithms like database indexing, not exceeding
an amount of time for accessing, inserting and deleting data.

Example of NLDS:
- Graphs
- Heaps
- Binary Tree

This project consist of studying and applying code examples about these structures in C++.


### Binary Search Tree (BST)

A type of Binary Tree where the elements are inserted ordered. Each node has at most two children,
organized in parent-child relationship. There are 2 main rules:
 - Nodes in left subtree have values less than the node's value
 - Nodes in right subtree have values greater than the node's value
